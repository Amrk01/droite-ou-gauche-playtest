Chiffrer le jeton GitHub de l'application de comptes

Tout se passe dans votre navigateur, rien n'est envoyé nulle part. Collez le jeton d'accès GitHub (fine-grained, limité au dépôt gaucheoudroite-compta, permission Contents en lecture et écriture) et choisissez la phrase de passe que vous partagerez avec Bandes Détournées. Enregistrez le résultat sous le nom jeton.json à côté de index.html, puis déployez.
