# Gaucheoudroite — appli de playtest

Appli mobile de playtest pour le jeu **Gaucheoudroite** (*Là où les extrêmes se rejoignent*).

Chaque joueur·euse ouvre la page sur son téléphone :

- **Roulette** : choisir sa position en secret, poser face cachée, révéler.
- **Mode de gauche** (collaboratif) : un téléphone gère la pile (10 items + 4 événements), les événements, le score et la repioche quand lea camarade ne connaît aucun des deux items.
- **Mode de droite** (compétitif) : tirage du bord politique par le boss, main de 5 cartes recto/verso par joueur.

Un seul fichier, aucune dépendance : `index.html`.
